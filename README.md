# qi-graph

建在 [qi-kv](../qi-kv) 上的两层存储，用奇语写成，共用一个 `.kv` 文件：

| 层 | 文件 | 是什么 |
|---|---|---|
| **图** | 图.qi · 遍历.qi · 图查询.qi · 图导入导出.qi | 属性图：节点 / 边 / 邻接 / BFS / DFS / 最短路径 / 三元组模式匹配 |
| **本体** | 本体.qi · 推理.qi · 本体导入导出.qi | RDFS 风味：类 / 属性 / 个体 / 三元组 / 子类闭包 / 定义域值域校验 / 四条规则物化推理 / Turtle |

两层各自独立可用，键空间用 `g:` 与 `o:` 前缀隔开。详细说明见 [README_图.md](README_图.md) 与 [README_本体.md](README_本体.md)。

```qi
导入 Graph::{打开图, 加节点, 加边, 最短路径, 关闭图};

变量 图: 整数 = 打开图("社交.kv");
加节点(图, "甲", "[\"人\"]", "{\"年龄\":30}");
加节点(图, "乙", "[\"人\"]", "{}");
加边(图, "", "认识", "甲", "乙", "{}");
变量 路: 整数 = 最短路径(图, "甲", "乙");   // 字符串列表句柄
关闭图(图);
```

```qi
导入 Graph::{打开本体, 定义类, 加个体, 是实例, 物化推理, 关闭本体};

变量 本: 整数 = 打开本体("动物.kv");
定义类(本, "动物");
定义类(本, "哺乳动物", "动物");
加个体(本, "旺财", "哺乳动物");
打印行(是实例(本, "旺财", "动物"));        // 1，走子类闭包
关闭本体(本);
```

## 设计要点

- **邻接不靠前缀扫**。qi-kv 的 `前缀列键` 是 O(全部槽) 线性扫，所以每个节点/主语一条邻接值（JSON 数组），
  取邻居、走闭包都是 O(1) 拿一条。前缀扫只留给「按标签列节点」「列出所有类」这种全局枚举。
- **名字里不能有冒号**。键靠 `:` 分段，含冒号的 id / 类名 / 谓词一律拒绝（返回 0）。
- **推理可撤销**。物化出来的三元组带 `inferred` 标记和来源（规则 + 前提），`解释` 能还原推导链，
  `撤销推理` 一次清干净，重复物化幂等。
- 批量灌数据开 qi-kv 的缓写（`开始批量` / `本体开始缓写`），快一个数量级。

## 命令行

```bash
qi compile 命令行/图工具.qi -o qigraph
qi compile 命令行/本体工具.qi -o qionto
```

## 边界

- 数据集受 qi-kv 约束：整个放得进内存，没有 fsync
- 没有事务；模式匹配是回溯而不是查询优化器，变量全开的模式会走全表
- 传递属性在大环上的物化是平方级；字面量宾语不进反向索引
- 边只存 id，取邻居要多读一次边 JSON；导出顺序是插入顺序不是字典序
