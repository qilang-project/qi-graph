# qi-graph

建在 [qi-kv](../qi-kv) 上的两层存储，用奇语写成，共用一个 `.kv` 文件：

| 层 | 文件 | 是什么 |
|---|---|---|
| **图** | 图.qi · 遍历.qi · 图查询.qi · 图导入导出.qi | 属性图：节点 / 边 / 邻接 / BFS / DFS / 最短路径 / 三元组模式匹配 |
| **图特征** | 图特征.qi | 把节点变成一串数：按标签度 / 三角形 / 聚类系数 / 自我网密度 / 测地 / 接近 / 介数 / PageRank / 个性化 PageRank / 元路径 DWPC / ReFeX |
| **图模式** | 图模式.qi | 抽出模式（类 / 属性 / 类型 / 端点）→ 跳过表蒸馏 → 挂说明 → 渲染成能塞进提示词的一段 |
| **图语句** | 图语句.qi | 一句话查图：`匹配 (?a:人)-[:认识]->(?b) 其中 ?a.年龄 > 30 返回 ?a 限制 10` |
| **图实体** | 图实体.qi | 命名实体消歧的存储侧：别名反查 / 候选 / 路径转文本 / 消歧上下文 / 合并节点 |
| **本体** | 本体.qi · 推理.qi · 本体导入导出.qi | RDFS 风味：类 / 属性 / 个体 / 三元组 / 子类闭包 / 定义域值域校验 / 四条规则物化推理 / Turtle |

两层各自独立可用，键空间用 `g:` 与 `o:` 前缀隔开。详细说明见 [README_图.md](README_图.md) 与 [README_本体.md](README_本体.md)。

```qi
导入 Graph::{打开图, 加节点, 加边, 最短路径, 关闭图};

变量 图: 整数 = 打开图("社交.kv");
加节点(图, "甲", "[\"人\"]", "{\"年龄\":30}");
加节点(图, "乙", "[\"人\"]", "{}");
加边(图, "", "认识", "甲", "乙", "{}");
变量 路: 整数 = 最短路径(图, "甲", "乙");   // 字符串列表句柄
关闭图(图);
```

```qi
导入 Graph::{打开本体, 定义类, 加个体, 是实例, 物化推理, 关闭本体};

变量 本: 整数 = 打开本体("动物.kv");
定义类(本, "动物");
定义类(本, "哺乳动物", "动物");
加个体(本, "旺财", "哺乳动物");
打印行(是实例(本, "旺财", "动物"));        // 1，走子类闭包
关闭本体(本);
```

```qi
导入 Graph::{打开图, 介数中心性, 个性化PageRank, 排行JSON, 节点特征JSON, 关闭图};

变量 图: 整数 = 打开图("社交.kv");
变量 介: 整数 = 介数中心性(图);              // id → 分数 的浮点表句柄
打印行(排行JSON(图, 介, 3));                 // [{"id":…,"分数":…}, …]
哈希表::释放表(介);

// 「站在这个节点的位置上，谁跟它最相关」—— 从一堆召回里挑该塞进提示的那几条
变量 个: 整数 = 个性化PageRank(图, "[\"甲\"]");
打印行(排行JSON(图, 个, 5));
哈希表::释放表(个);

打印行(节点特征JSON(图, "甲"));               // 一行特征向量，喂给下游模型
关闭图(图);
```

```qi
导入 Graph::{打开图, 查, 图模式文本, 消歧上下文, 关闭图};

变量 图: 整数 = 打开图("知识.kv");
打印行(图模式文本(图));                       // 给模型看的模式 + 怎么查
打印行(查(图, "匹配 (?a:人)-[:认识]->(?b:人) 其中 ?a.年龄 > 30 返回 ?a, ?b 限制 10"));
打印行(消歧上下文(图, "qi", "[\"LLVM21\"]"));  // 「qi」指哪个实体？把路径翻成人话给模型
关闭图(图);
```

## 设计要点

- **邻接不靠前缀扫**。qi-kv 的 `前缀列键` 是 O(全部槽) 线性扫，所以每个节点/主语一条邻接值（JSON 数组），
  取邻居、走闭包都是 O(1) 拿一条。前缀扫只留给「按标签列节点」「列出所有类」这种全局枚举。
- **名字里不能有冒号**。键靠 `:` 分段，含冒号的 id / 类名 / 谓词一律拒绝（返回 0）。
- **推理可撤销**。物化出来的三元组带 `inferred` 标记和来源（规则 + 前提），`解释` 能还原推导链，
  `撤销推理` 一次清干净，重复物化幂等。
- 批量灌数据开 qi-kv 的缓写（`开始批量` / `本体开始缓写`），快一个数量级。
- **图特征的方向约定**：社群结构类（三角形 / 聚类 / 密度 / 测地 / 接近 / 介数）一律当无向图算、
  自环剔掉；PageRank 按有向算（方向就是它的全部内容）。要无向 PageRank 就每条边正反各加一次。
  重复边一律只算一条，边属性上的权重**不读**。
- **算法代价**：邻接每次回 kv 读，没有内存图。度 / 三角形 / 密度 / 单点特征都是局部的，随便用；
  接近中心性（全图）和介数中心性是 O(点 ×(点+边))，几千个点就该先 `导出JSON` 到内存里算。

## 依赖

图层与本体层都建在 [qi-kv](https://github.com/qilang-project/qi-kv) 上，`qi.toml` 里
声明成注册中心依赖。**先装一次再编**（在 monorepo 里也一样 —— 声明了注册中心依赖之后
祖先目录扫描就不管用了）：

```bash
qi 包 安装      # KV 0.1.0 → qi_packages/KV
```

## 命令行

```bash
qi compile 命令行/图工具.qi -o qigraph
qi compile 命令行/本体工具.qi -o qionto
```


## 边界

- 数据集受 qi-kv 约束：整个放得进内存，没有 fsync
- 没有事务；模式匹配是回溯而不是查询优化器，变量全开的模式会走全表
- 传递属性在大环上的物化是平方级；字面量宾语不进反向索引
- 边只存 id，取邻居要多读一次边 JSON；导出顺序是插入顺序不是字典序
