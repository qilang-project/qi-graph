# qi-graph · 本体层

建在 qi-kv 上的轻量本体存储：类 / 属性 / 个体 / 三元组，带子类闭包、定义域值域校验、
四条规则的物化推理，以及 JSON / Turtle 导出。RDFS 风味，不追 OWL。

三个模块，零 Rust，只用 qi-kv 和标准库的 JSON / 字符串 / 列表 / 哈希表：

| 模块 | 管什么 |
|---|---|
| `本体.qi` | 打开关闭、类、属性、个体、三元组断言与查询、传递闭包、链式 `本体库` |
| `推理.qi` | 祖先/后代闭包、含继承的类型判断、`校验`、`物化推理` / `撤销推理` / `解释` |
| `本体导入导出.qi` | `导出本体JSON` / `导入本体JSON` / `导出Turtle` |

```qi
导入 Graph::{开本体, 本体库};

变量 本: 本体库 = 开本体("知识.kv")
    .定义类("动物")
    .定义类("狗", "动物")
    .定义属性("朋友", "动物", "动物", "{\"symmetric\":1}")
    .加个体("旺财", "狗")
    .加个体("咪咪", "动物")
    .断言("旺财", "朋友", "咪咪")
    .物化推理();
打印行(本.是实例("旺财", "动物"));            // 1
打印行(本.有三元组("咪咪", "朋友", "旺财"));   // 1 —— 对称推出来的
打印行(本.解释("咪咪", "朋友", "旺财"));       // 推出：咪咪 朋友 旺财 ← 规则「对称」，前提：旺财 朋友 咪咪
本.关();
```

## 数据模型

底层统一表示是三元组 `(主语, 谓词, 宾语)`。类、属性、个体的断言最终都落成三元组，
谓词名用中文：

| RDF/RDFS | 这里 |
|---|---|
| `rdf:type` | `类型是` |
| `rdfs:subClassOf` | `父类是` |
| `rdfs:subPropertyOf` | `父属性是` |
| `rdfs:domain` / `rdfs:range` | `定义域` / `值域` |

- **类**：名字、可选父类（多继承允许，多次 `定义类(名, 父)` 即可）、注释
- **属性**：名字、定义域（类）、值域（类，或字面量类型 `字符串` / `整数` / `浮点数` / `布尔`）、
  是否函数性、可选父属性、`传递` / `对称` / `逆属性` 标记
- **个体**：id、直接类型（可多个）、属性值
- **宾语**两种形状：个体 `{"iri":"旺财"}`，字面量 `{"lit":"3","dt":"整数"}`

名字（主语 / 谓词 / 类 / 属性 / 个体 id）**不能含 `:`**（键的分段符），**不能以 `lit=` 开头**
（字面量在键里的前缀）。违反的写入返回 0，什么都不动。字面量的**值**不受限制。

## 键空间

全部放在 qi-kv 同一个库里，`o:` 前缀，`:` 分段：

| 键 | 值 | 用途 |
|---|---|---|
| `o:spo:<主>:<谓>:<宾键>` | `"1"` 或解释 JSON | 三元组存在性 O(1)；值 `"1"` = 断言，否则是推出来的（存规则 + 前提） |
| `o:pos:<谓>:<宾键>:<主>` | 同上 | 反向标记 |
| `o:s:<主>` | `[{"p","o",("inferred":1)}]` | **正向邻接**，按主语一次拿全 |
| `o:o:<宾键>` | `[{"s","p",("inferred":1)}]` | **反向邻接**（只收个体宾语），按宾语一次拿全 |
| `o:c:<类>` | `{"name","comment"}` | 类定义；父类不双写，走 `父类是` 三元组 |
| `o:p:<属性>` | `{"name","domain","range","functional","transitive","symmetric","inverse","parent"}` | 属性定义 |
| `o:i:<个体>` | `{"id","types":[…]}` | 个体 + 直接类型 |

宾键：个体就是 id，字面量是 `lit=<值>`。`查` / `撤销` / `解释` 里要指字面量宾语时也写 `lit=<值>`。

邻接查询（按主语 / 按宾语 / 沿谓词走闭包）全是 O(1) 拿一条 JSON；`前缀列键` 那种 O(全部槽)
的线性扫只用在 `列出类` / `列出属性` / `列出个体` / `列出主语`（全局枚举）和 `查("", "", "")`
这类不带主语也不带个体宾语的查询上。

## API

自由函数是本体，`本体库` 的方法是一行转发；返回列表句柄的用完 `列表::删除列表`，
返回 JSON 文本的直接用。缺失返回空串 / 0 / 空列表，不抛异常。

**开关**：`打开本体(路径)` · `关闭本体` · `本体可用` · `本体开始缓写` / `本体刷盘`（批量灌数据时透传 qi-kv 的缓写）· `开本体(路径) : 本体库`

**类**：`定义类(本, 名)` / `定义类(本, 名, 父类)` · `类存在` · `类注释(本, 名, 注释)` · `类定义(本, 名) : JSON` ·
`父类(本, 类) : 列表` · `子类(本, 类) : 列表` · `列出类(本) : 列表`（字典序）

**属性**：`定义属性(本, 名, 定义域, 值域)` / `定义属性(本, 名, 定义域, 值域, 选项JSON)` · `属性存在` ·
`属性定义(本, 名) : JSON` · `属性字符串字段` / `属性整数字段` · `列出属性`

选项 JSON 的键：`functional` / `transitive` / `symmetric`（1 或 true）、`inverse` / `parent`（属性名）；
也认中文别名 `函数性` / `传递` / `对称` / `逆属性` / `父属性`。逆属性只需在一边声明，另一边定义时自动认领。

**个体**：`加个体(本, id, 类)`（类可空）· `个体存在` · `个体类型(本, id) : 列表`（直接类型）·
`按类列个体(本, 类)` / `按类列个体(本, 类, 含子类)` · `列出个体` · `删除个体(本, id)`（连同提到它的三元组）

**三元组**：`断言(本, 主, 谓, 宾)` · `断言字面量(本, 主, 谓, 值, 数据类型)` · `撤销(本, 主, 谓, 宾)` ·
`撤销字面量` · `有三元组` · `三元组标记(本, 主, 谓, 宾)`（`""` 没有 / `"1"` 断言 / 否则是解释 JSON）·
`查(本, 主, 谓, 宾) : JSON 数组`（任一位置空串当通配）· `值(本, 主, 谓) : 列表` · `主语(本, 谓, 宾) : 列表` ·
`三元组数` · `列出主语` · `邻接(本, 主) : JSON 数组句柄`（要自己 `JSON.删除`）

**推理**：`所有祖先类(本, 类)` · `所有子类` · `所有父属性` · `是子类(本, 子, 祖)`（自反）·
`所有类型(本, 个体)`（含继承）· `是实例(本, 个体, 类)` · `校验(本) : JSON 数组` ·
`物化推理(本) : 新增数` · `撤销推理(本) : 清掉数` · `推出三元组数` · `解释(本, 主, 谓, 宾) : 字符串`

**导入导出**：`导出本体JSON(本)` · `导入本体JSON(本, 文本) : 条数`（解析失败 -1）· `导出Turtle(本)`。
方法名是 `.导出JSON()` / `.导入JSON(文本)` / `.导出Turtle()`。自由函数带「本体」二字是为了跟图层的
`导出JSON` 分开 —— 两层都 `公开 导入` 进同一个 `Graph` 包，同名同元数会撞。

**工具**：`传递闭包(本, 起点, 谓, 逆向)` · `排序字符串列表(表) : 新列表` · `比较字符串` · `字符串列表含` · `字符串列表连成行`

## 校验

`校验(本)` 全库体检，返回 `[{"kind","s","p","o","msg"}]`：

| kind | 什么意思 |
|---|---|
| `domain` | 主语不是该属性定义域的实例（含继承） |
| `range` | 宾语不是值域的实例；值域是字面量类型时，宾语必须是同数据类型的字面量 |
| `functional` | 函数性属性在同一主语上多个值（每个 `(主, 谓)` 只报一次） |
| `unknown_class` | `类型是` / 父类 / 定义域 / 值域 引用了没定义的类 |
| `unknown_property` | 谓词 / 父属性 / 逆属性 没定义 |

推出来的三元组也一并校验。

## 推理

四条规则，**物化**到库里（带 `inferred` 标记，`o:spo` 的值存规则和前提），
朴素迭代：每一轮对库里每条非模式三元组套一遍规则，一轮没有新增就停（不动点）。

| 规则 | 前提 | 结论 |
|---|---|---|
| 子属性 | `(s p o)`，`p ⊑* q`（父属性是 的闭包） | `(s q o)`，字面量宾语也抬 |
| 传递 | p 传递，`(a p b)`，`(b p c)` | `(a p c)` |
| 对称 | p 对称，`(a p b)` | `(b p a)` |
| 逆属性 | p 逆 q，`(a p b)` | `(b q a)`（两边都登记了，所以两个方向都触发） |

- 重复跑幂等：已有的（断言或推出）不再写，`物化推理` 第二次返回 0
- 断言一条跟推出重合的三元组会**升级成断言**（拆掉重放），之后 `撤销推理` 不动它
- `撤销推理` 清掉全部带标记的，断言的一条不少
- `解释(本, 主, 谓, 宾)` 给人看：`断言：…` / `不存在：…` /
  `推出：… ← 规则「传递」，前提：a p b；b p c`，前提本身是推出来的会标 `（推出）`
- 类层次（`父类是`）**不物化**，`所有祖先类` / `所有类型` / `是实例` 按需走闭包，带环也停

传递属性的闭包是平方级的：一条 2000 个体的环做传递闭包会生成 400 万条三元组，别对这种数据开 `transitive`。

## 导入导出

`导出本体JSON` 键序稳定：类 / 属性 / 个体 / 主语按字节序，同一主语下按 `(谓词, 宾键)` 排，
所以**插入顺序不同的等价本体导出逐字节相等**。只导断言的三元组，推出来的重跑 `物化推理` 即可。
`导入本体JSON` 可以灌进非空库，已有的跳过，幂等。

```json
{"classes":[{"name","comment","parents":[]}],
 "properties":[{"name","domain","range","functional","transitive","symmetric","inverse","parent"}],
 "individuals":[{"id","types":[]}],
 "triples":[{"s","p","o":{"iri"}|{"lit","dt"}}]}
```

`导出Turtle` 是给人看的极简子集：前缀省略，`:主 :谓 :宾 .`，字符串字面量加引号（转义 `\` `"` 换行），
整数/浮点数裸写，布尔 `true`/`false`，推出来的行尾 `# 推出`。**不是**可回读的 Turtle。

## 命令行

```bash
qi compile 命令行/本体工具.qi -o qionto

qionto 定义类 狗 --父类 哺乳动物 --注释 汪
qionto 定义属性 年龄 --定义域 动物 --值域 整数 --函数性
qionto 定义属性 养 --定义域 人 --值域 动物 --逆属性 被养
qionto 加个体 旺财 狗
qionto 断言 旺财 年龄 3 --字面量 --类型 整数
qionto 查 --主 旺财              # 文本行；--JSON 出 JSON
qionto 类 狗                     # 祖先 / 后代 / 个体
qionto 个体 旺财                 # 类型 / 三元组 / 被引用
qionto 校验                      # 有问题退出码 1
qionto 推理                      # 物化到不动点；--撤销 清掉
qionto 解释 旺财 被养 小明
qionto 导出 --格式 turtle
qionto 导出 > 本体.json && qionto --库 别的.kv 导入 本体.json
qionto 统计
```

库文件默认 `$HOME/.qigraph.kv`，`--库` 换。每条命令都是「开库 → 做一件事 → 关库」。


| 套件 | 用例 | 断言 | 盖到什么 |
|---|---|---|---|
| `本体_测` | 10 | 150 | 类（多继承、冒号拒绝）、属性（选项、逆属性认领）、个体（类型同步、删除个体清两向）、三元组（六种通配组合、字面量）、重开、链式、排序、2000 个体 / 10000 三元组规模 |
| `推理_测` | 18 | 106 | 菱形闭包、自环、含继承的实例、校验五种问题各有正反例、四条规则各一 + 传递×对称组合、幂等 / 升级断言 / 撤销、解释、重开后推理还在、规模 |

规模（MacBook，2000 个体 / 10000 三元组，开缓写）：写 ≈ 0.6 s，2000 次按主语取值 15 ms，
全局扫数三元组 30 ms，重开重放 ≈ 0.4 s，`校验` ≈ 0.4–0.6 s，对称物化 6000 条 ≈ 0.7–1.1 s，撤销推理 ≈ 0.4 s。

## 边界与取舍

- 一条三元组 = 4 次 qi-kv 写（spo / pos 两个标记 + 两份邻接数组重写）。邻接数组重写是 O(度)，
  超高入度的宾语（比如所有个体都 `类型是 动物`）每加一条都要重写一次几千元素的 JSON —— 万级还行，十万级要换结构
- 字面量的宾键是 `lit=<值>`，不带数据类型：同一主谓下 `"3"^^整数` 和 `"3"^^字符串` 是同一条
- 字面量宾语不进反向邻接，`查("", 谓, "lit=…")` 走全局扫
- 推理是朴素迭代，不是半朴素（semi-naive）：每轮都扫全库，轮数 = 推导链最长深度 + 1
- 没有 `owl:sameAs` / 基数约束 / 不相交类；`校验` 只报不改
- 排序只用在导出和 `列出*`，靠 `字节切片::比较` 做字节序 —— 这是本层唯一碰 qi-kv 五件套之外的标准库模块
- `导出Turtle` 只出不进
